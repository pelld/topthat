# Top That

This mock-up turns the single-deck prototype into a small site.

## Included

- Home screen with six choices:
  - Animals
  - Countries
  - Space
  - Vehicles
  - Big Things
  - Chaos
- Topic-specific card styling and statistics.
- Existing alternating left/right game mechanic.
- Home and Change Topic controls in the game.
- A short educational fact on each card.
- Chaos mode demonstrates cross-topic comparisons using shared real-world measurements.

## Data

The mock-up deliberately uses a small sample of cards so the interaction can be reviewed before building the full dataset.

The repo version could expand to roughly 50 cards per normal topic and a curated 50-card Chaos deck.
